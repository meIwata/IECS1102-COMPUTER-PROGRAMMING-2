# SQL查詢快速複習指南

## 🎯 核心語法結構記憶法

### SELECT語句的萬能公式
```
SELECT 要什麼 FROM 從哪來 WHERE 什麼條件 GROUP BY 怎麼分組 HAVING 分組條件 ORDER BY 怎麼排序
```

**記憶口訣：「選從哪條分有序」**
- **選**：SELECT 選什麼欄位
- **從**：FROM 從哪個表
- **哪**：WHERE 哪些條件
- **條**：GROUP BY 條件分組
- **分**：HAVING 分組後篩選
- **有**：ORDER BY 有序排列

## 📚 基本查詢速記

### 1. 基本SELECT (選擇器)
```sql
-- 記憶：* 代表全部，像是「全拿」
SELECT * FROM table;

-- 記憶：AS 就是「叫做」
SELECT name AS 姓名 FROM Customers;

-- 記憶：DISTINCT 去重複，想成「與眾不同」
SELECT DISTINCT class FROM OrderDetails;
```

### 2. WHERE條件 (篩選器)
```sql
-- 數字比較：> < >= <= = !=
WHERE age > 18

-- 記憶技巧：把WHERE想成「在哪裡符合條件」
WHERE name = '王小明'
WHERE accumulated_miles BETWEEN 1000 AND 5000  -- 記憶：「在...之間」
WHERE customer_id IN ('C001', 'C002')          -- 記憶：「在...裡面」
```

### 3. LIKE模糊查詢 (搜尋器)
```sql
-- 記憶口訣：「前%後%中間%」
WHERE name LIKE '王%'      -- 以王開頭
WHERE name LIKE '%明%'     -- 包含明  
WHERE name LIKE '%華'      -- 以華結尾
```

### 4. NULL處理 (空值檢查器)
```sql
-- 記憶：IS NULL / IS NOT NULL (不能用 = NULL)
WHERE phone IS NULL        -- 沒有電話
WHERE phone IS NOT NULL    -- 有電話
```

## 🔧 進階功能速記

### 5. 統計函數 (計算器)
```sql
-- 記憶口訣：「總平最多少」
COUNT(*)     -- 總數量 (Total)
AVG()        -- 平均值 (Average)  
MAX()        -- 最大值 (Maximum)
MIN()        -- 最小值 (Minimum)
SUM()        -- 總和 (Sum)
```

### 6. GROUP BY + HAVING (分組器)
```sql
-- 記憶：GROUP BY 是「按什麼分組」，HAVING 是「分組後的條件」
SELECT customer_id, COUNT(*) 
FROM Orders 
GROUP BY customer_id           -- 按客戶分組
HAVING COUNT(*) > 2;          -- 分組後：訂單數 > 2
```

**重要區別記憶法：**
- **WHERE**：分組前篩選 (個體條件)
- **HAVING**：分組後篩選 (群體條件)

## 🔗 JOIN連接速記

### 7. JOIN類型 (連接器)
```sql
-- 記憶圖像法：
INNER JOIN    -- 交集：只要共同部分 ⚪
LEFT JOIN     -- 左全：左邊全留，右邊配對 ⚪⚫  
RIGHT JOIN    -- 右全：右邊全留，左邊配對 ⚫⚪
CROSS JOIN    -- 笛卡兒：全部組合 (少用)
```

**JOIN記憶口訣：「內左右交」**

### 8. 實用JOIN範例
```sql
-- 客戶與訂單：「誰買了什麼」
SELECT c.name, o.total_amount
FROM Customers c 
INNER JOIN Orders o ON c.customer_id = o.customer_id;

-- 多表連接：「一氣呵成」
SELECT c.name, f.flight_no, t.seat_no
FROM Customers c
JOIN Orders o ON c.customer_id = o.customer_id  
JOIN Tickets t ON o.order_id = t.order_id
JOIN Flights f ON t.flight_id = f.flight_id;
```

## ⚡ 快速記憶技巧

### 9. 邏輯運算子
```sql
-- 記憶：AND 要「同時滿足」，OR 要「其中一個滿足」  
WHERE age > 18 AND gender = '男'    -- 成年男性
WHERE city = '台北' OR city = '高雄'  -- 北高兩市
```

### 10. 子查詢 EXISTS
```sql
-- 記憶：EXISTS = 「存在嗎？」
WHERE EXISTS (SELECT 1 FROM ...)    -- 如果存在...
WHERE NOT EXISTS (SELECT 1 FROM ...) -- 如果不存在...
```

### 11. UNION聯集
```sql
-- 記憶：UNION = 「合併」，像是把兩個清單併在一起
SELECT name FROM Customers
UNION  
SELECT passenger_name FROM Tickets;
```

## 🏆 實戰記憶策略

### 記憶順序建議：
1. **先記基礎**：SELECT, FROM, WHERE
2. **再記統計**：COUNT, SUM, AVG
3. **然後分組**：GROUP BY, HAVING
4. **最後連接**：各種JOIN

### 練習口訣：
- **查詢邏輯**：「我要什麼？從哪來？什麼條件？」
- **JOIN邏輯**：「誰和誰？怎麼連？連什麼？」
- **分組邏輯**：「按什麼分？分完算什麼？有什麼條件？」

## 💡 常見陷阱提醒

1. **JOIN一定要有ON條件** (否則變CROSS JOIN)
2. **GROUP BY後只能SELECT分組欄位或統計函數**
3. **HAVING必須配合GROUP BY使用**
4. **WHERE不能用統計函數，要用HAVING**
5. **NULL值比較必須用IS NULL，不能用=**

記住這些口訣和技巧，SQL查詢就能快速上手！
